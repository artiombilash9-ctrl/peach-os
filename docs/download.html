GitHub limita a 2 GiB ogni file allegato ai Release: per questo le ISO sono divise in due parti. La somma di controllo è calcolata sull'ISO ricomposta, non sulle singole parti.

Ricompilare e verificare

  1. Scarica entrambe le parti dell'architettura scelta e mettile nella stessa cartella (per esempio release-assets/).
  2. Ricompila l'ISO: ./tools/join-iso.sh amd64 (oppure i386). Lo script è nel repository, cartella tools/.
  3. Verifica il checksum stampato dallo script: deve coincidere con il valore nel file .sha256 del Release.
  4. Scrivi su USB: dd if=PeachOS-1.0-amd64.iso of=/dev/sdX bs=4M status=progress — controlla due volte il nome del dispositivo. Su Windows usa Rufus o balenaEtcher.

Vuoi partire dai sorgenti invece? Leggi la guida alla build nel README.
